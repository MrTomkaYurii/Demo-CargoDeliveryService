# 📦 Модуль Замовлень Вантажоперевезень (CargoOrderingService)

## 📌 Огляд модуля
Модуль **`CargoOrderingService`** відповідає за створення та управління замовленнями на транспортування вантажів клієнтами.

## 🏛️ Архітектурні особливості
- Побудований на принципах **Clean Architecture** та **CQRS (Command Query Responsibility Segregation)**.
- Використовує патерн Mediator (MediatR), Domain Events та FluentValidation.

## 📁 Структура проєктів:
- `CargoOrderingService` (Core, Application, Infrastructure)
- `CargoOrderingService.UnitTests`
- `CargoOrderingService.IntegrationTests`
- `CargoOrderingService.FunctionalTests`
