# 📝 Модуль Управління Блогом Водіїв (DriversBlogManagement)

## 📌 Огляд модуля
Модуль **`DriversBlogManagement`** забезпечує внутрішній корпоративний портал та комунікацію між диспетчерами й водіями автопарку.

## 🏛️ Архітектурні особливості
- Побудований на принципах мікросервісної / модульної Clean Architecture.
- Включає функціональні, інтеграційні та модульні тести.

## 📁 Структура проєктів:
- `DriversBlogManagement` (Core, Application, Infrastructure)
- `DriversBlogManagement.UnitTests`
- `DriversBlogManagement.IntegrationTests`
- `DriversBlogManagement.FunctionalTests`
